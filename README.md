# Skin Packs

Skin Packs is a RuneLite plugin project for working with game skin packs.

## Development

Build and run the plugin locally with the Gradle wrapper:

```powershell
.\gradlew build
.\gradlew run
```

The project uses the RuneLite Plugin Hub example-plugin layout and Java 11
compatibility. The plugin implementation is a starter scaffold; skin-pack
functionality has not been added yet.

## Plugin Hub

Before submitting to the [RuneLite Plugin Hub](https://github.com/runelite/plugin-hub),
update `runelite-plugin.properties` with the final description, tags, and version.
Follow the Plugin Hub's current [submission guidelines](https://github.com/runelite/plugin-hub#submitting-plugins).
